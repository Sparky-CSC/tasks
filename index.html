🖥️ Browser Print
🌐 Network Bridge

Uses your browser's built-in print dialog. Works with any printer shared on your network — just select it in the dialog. For best results, set paper size to 80mm × auto (or 58mm) and margins to None in the print dialog.

Sends ESC/POS commands directly to a local HTTP bridge running on the same network (e.g. escpos-tools, QZ Tray, or a simple Node.js bridge). The bridge must be reachable from this browser.

Full URL the bridge listens on for POST requests
Quick Node.js bridge (save as bridge.js, run with node): 
const http=require('http');
const {exec}=require('child_process');
http.createServer((req,res)=>{
  res.setHeader('Access-Control-Allow-Origin','*');
  res.setHeader('Access-Control-Allow-Headers','*');
  if(req.method==='OPTIONS'){res.end();return;}
  let body='';
  req.on('data',d=>body+=d);
  req.on('end',()=>{
    // body.text = plain-text receipt content
    const txt=JSON.parse(body).text||'';
    // lp / lpr example — adjust printer name
    exec(`echo "${txt.replace(/"/g,"'")}" | lpr -P receipt`, ()=>{});
    res.end('ok');
  });
}).listen(8080,()=>console.log('Bridge on :8080'));
